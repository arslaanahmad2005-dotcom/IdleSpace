# 🏢 IdleSpace

> **Turn unused space into opportunity.**

IdleSpace is a modern marketplace platform that connects **property owners** with **businesses, creators, professionals, and individuals** looking for temporary commercial spaces.

Users can discover and book spaces such as **restaurants, studios, kitchens, classrooms, meeting rooms, offices, and event spaces** on an hourly basis, while space owners can list and monetize their unused spaces.

### 🚀 Built For

* **Space Seekers** — Find flexible spaces for work, meetings, events, classes, and creative activities.
* **Space Owners** — List unused spaces, set pricing, and turn vacant hours into revenue.

**IdleSpace — Find a space. List a space. Make every hour count.**
