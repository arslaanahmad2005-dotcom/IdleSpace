# IdleSpace

IdleSpace is a platform that connects property owners with businesses and individuals looking for temporary commercial spaces. It makes it easy to discover, list, and book underutilized spaces through a simple and user-friendly interface.

## Features

- Secure User Authentication
- Property Listings
- Search & Filters
- Booking Management
- Responsive UI

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- TanStack Start

## Getting Started

```bash
git clone <repository-url>
cd <project-folder>
npm install
npm run dev
